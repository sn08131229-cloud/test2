# 运行与 GitHub 发布说明（V1）

## 1. 本地启动
### 前端（VS Code）
```bash
cd frontend
npm install
npm run dev
```
访问：`http://localhost:5173`

### 后端（IDEA）
- 打开 `backend` 工程
- 运行主类：`com.example.trace.TraceApplication`

或命令行：
```bash
cd backend
mvn spring-boot:run
```
访问：`http://localhost:8080`

## 2. 上传到 GitHub（给别人查看）
> 当前仓库还没有配置远程地址，需要你绑定你的 GitHub 仓库后再 push。

### 第一步：在 GitHub 新建仓库
例如：`medical-device-trace-v1`

### 第二步：在本地绑定远程仓库
```bash
git remote add origin https://github.com/<你的用户名>/medical-device-trace-v1.git
```

### 第三步：推送当前分支
```bash
git branch -M main
git push -u origin main
```

推送成功后，打开：
`https://github.com/<你的用户名>/medical-device-trace-v1`

## 4. 常见问题
### 4.1 打开 localhost:5173 提示无法访问
请确认前端命令窗口没有退出，并且执行过：
```bash
npm install
npm run dev
```

### 4.2 后端连不上 MySQL
请检查 `backend/src/main/resources/application-dev.yml` 的数据库账号密码是否改成你的本机配置。

### 4.3 后端连不上 WeBASE-Front
请检查 `chain.webaseFrontUrl` 是否填写 Ubuntu 虚拟机实际 IP（不要写死 127.0.0.1）。

## 5. 合约说明
- 已提供合约文件：`contract/DeviceTrace.sol`
- 方法：`registerDevice`、`addFlowRecord`、`getDeviceFlowCount`、`getDeviceFlowByIndex`、`getLatestDeviceStatus`
- 你在 WeBASE-Front 部署后，把合约地址回填到：`backend/src/main/resources/application-dev.yml` 的 `chain.contractAddress`。
